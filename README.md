## TP53
repository for all analyses performed to investigate TP53 and its isoforms; *i.e.* $p53\alpha$, $p53\beta$, $p53\gamma$, $\Delta40p53\alpha$, $\Delta40p53\small\beta$, $\Delta133p53\alpha$, $\Delta133p53\small\beta$, $\Delta160p53\alpha$. \
genomic (NGS and FISH), transcriptomic (bulk RNA), and proteomic (western-blot) data were all studied. for genomic and transcriptomic data, MMRF CoMMpass data (release IA22) was handled to investigated newly-diagnosed Multiple Myeloma patients to find any correlation with clinical data of the same patients.
