# TP53
repository for all analyses performed to investigate TP53 and its isoforms; *i.e.* $\small\p53alpha$, $\small\p53beta$, $\small\p53gamma$, $\small\Delta40p53\alpha$, $\small\Delta40p53\small\beta$, $\small\Delta133p53\alpha$, $\small\Delta133p53\small\beta$, $\small\Delta160p53\alpha$. 
genomic, transcriptomic, and proteomic (western-blot) data were all studied. for genomic and transcriptomic data, MMRF CoMMpass data (release IA22) was handled to investigated newly-diagnosed Multiple Myeloma patients to find any correlation with clinical data of the same patients.
